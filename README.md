# Bestell-App

A responsive frontend demo that simulates the ordering workflow of a restaurant delivery application. The project was originally developed as part of frontend training and is currently being prepared for use as a professional portfolio project.

## Overview

The application renders a restaurant menu from JavaScript data and allows users to build and manage a shopping basket. Prices, delivery costs, and the final order total are calculated dynamically.

This is a portfolio demo. It does not represent a real restaurant or process real food orders.

## Features

- Dynamic rendering of dishes from JavaScript data
- Add dishes to the shopping basket
- Increase or decrease item quantities
- Remove individual dishes from the basket
- Dynamic subtotal calculation
- Fixed delivery cost calculation
- Dynamic total price calculation
- Test-order workflow with confirmation feedback
- Responsive desktop and mobile basket behavior
- Contact form with HTML validation and local demo confirmation
- Legal notice page
- Privacy policy link
- Responsive layouts for desktop, tablet, and mobile viewports

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frontend framework is used.

## Application Logic

Dish data is stored in `js/db.js`. The menu and basket markup are generated by template functions in `js/template.js`. `script.js` manages application state, basket interactions, price calculations, responsive basket behavior, and test-order feedback. `js/contact.js` handles the contact form locally and does not transmit entered data to an external service.

## Running Locally

No build process or package installation is required.

1. Clone or download the repository.
2. Open the project directory.
3. Serve the project with a local development server or open `index.html` in a browser.

Using a local development server is recommended so that relative paths behave consistently.
