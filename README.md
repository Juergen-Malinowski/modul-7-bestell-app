# Bestell-App

Bestell-App is an early frontend learning project created during my web development training. Its main purpose was to practise dynamic shopping-basket functionality, price calculations, application state, and interactive frontend behaviour with JavaScript.

The project is currently being revised for use as a portfolio project while intentionally keeping the original Vanilla JavaScript approach.

## Overview

The application renders a restaurant menu from JavaScript data and allows users to add dishes to a shopping basket, change quantities, remove items, and complete a simulated order. Subtotal, delivery costs, and total price are calculated dynamically.

The ordering workflow is a demonstration only. No real food orders are transmitted or stored.

## Features

- Dynamic rendering of dishes from JavaScript data
- Add dishes to the shopping basket
- Increase and decrease item quantities
- Remove individual dishes from the basket
- Dynamic subtotal calculation
- Delivery cost calculation
- Dynamic total price calculation
- Test-order workflow with confirmation feedback
- Separate desktop and mobile basket behaviour
- Contact form with HTML validation and local demo confirmation
- Legal notice and privacy policy pages
- Navigation back to the start page from secondary pages
- Responsive layouts for desktop, tablet, and mobile viewports

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No frontend framework or build process is required.

## Application Logic

Dish data is stored in `js/db.js`. The menu and basket markup are generated by template functions in `js/template.js`. `script.js` manages application state, basket interactions, price calculations, responsive basket behaviour, and test-order feedback.

`js/contact.js` handles the contact form locally. Entered form data is validated in the browser and is not transmitted to an external form service.

`js/page.js` resets restored scroll positions when pages are loaded so navigation and reloads start at the top of the page.

## Typography and External Requests

The heading uses the locally hosted **Kaushan Script** font. The font is stored inside the repository and is not loaded from an external font service at runtime.

## Privacy and Legal Pages

The project includes:

- an explanation that the contact form works locally,
- an explanation that the order function is a demonstration only.

The current privacy policy reflects the intended deployment with ALL-INKL.COM and the present behaviour of the application.

## Running Locally

1. Clone or download the repository.
2. Open the project directory.
3. Serve the project with a local development server.
4. Open `index.html` in the browser.

Using a local development server is recommended so relative paths behave consistently.
